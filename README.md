# Coffee or Tea

One Letter: Coffee or Tea — an entry for the make.fun bounty
[u-rusdyxbt-one-letter-coffee-or-tea-89877fa0](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0).
The program writes exactly one letter, **A** for coffee, to `/output/entry.txt`.

## Run

```sh
node main.ts
```

This writes the single letter `A` to `/output/entry.txt` — nothing else, no
newline, no explanation, no punctuation.
